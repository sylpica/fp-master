# DECISIONS（設計判断の記録）

- **D-001 静的PWA（React+TS+Vite）**：GitHub Pages で動かすためバックエンドなし。ルーティングは HashRouter（Pages の404回避）。
- **D-002 Tailwind CSS 4**：独自部品は `@utility` で定義（v4 は @layer components の @apply 参照不可のため）。
- **D-003 IndexedDB（Dexie）**：学習履歴・復習・設定はすべて端末内。端末間同期はしない（GitHub Pages 単体では不可能。バックアップで代替）。
- **D-004 問題データはJSONを遅延 import**：セット単位で別チャンク。PWA が全JSONをプリキャッシュしオフライン演習可能。
- **D-005 間隔反復は SM-2**：FSRS は精度が高いがパラメータ最適化に十分な履歴が必要で、個人利用の初期データでは利点が小さい。
  SM-2 は挙動が単純でテスト・説明が容易。評価は 不正解=again(1)／正解だが自信なし=hard(3)／正解=good(4)／覚えた=good。
  初回 2日・2回目 6日・以降 EF倍、上限365日。`domain/srs.ts` に独立させているので将来 FSRS へ置換可能。
- **D-006 厳密計算**：金額・利回りは BigInt 有理数（`domain/decimal.ts`）で計算し、問題文に端数処理を明記。数値入力の照合は小数桁を揃えた整数比較。
- **D-007 計算問題の判定基準**：与えられた数値に対して計算操作（比率・加減乗除・分数）を行わないと答えが出ない問題を true。
  公式・計算式が選択肢に示されていて知識で選べるもの、数値を暗記していれば答えられるもの、最小値を選ぶだけのもの（上場株式評価など）は false。
  1つの選択肢だけに計算が含まれる「次の記述のうち」型は、問題の中心が計算でなければ false。判定は全問目視で行い理由を `calcReason` に記録。
- **D-008 図表を含む問題**：テキスト化すると表が崩れるため、原本PDFの該当範囲（問題見出し直後〜選択肢直前）を画像として切り出して表示し、
  本文テキストはスクリーンリーダー・検索用に保持。選択肢自体が分数式の問題（2級2025年1月 問23）は再現できないため隔離。
- **D-009 合格到達度**：統計モデルの合格確率は出さない（根拠データ不足）。直近正答率・模試得点率・網羅率の加重平均を「到達度スコア」として段階表示し、
  直近30問未満は「データ不足」とする。
- **D-010 根拠照合（evidence）**：用語・カード・改正情報に「出典ページ本文に含まれる引用」を持たせ、スクリプトで照合できたものだけ verified。
  毎週の GitHub Actions で再照合し、引用が消えたら draft/candidate へ格下げ＋Issue 作成（自動で内容を書き換えない）。
  照合は「根拠の存在」の確認であり、説明文全体の正しさを機械的に保証するものではない（KNOWN_ISSUES 参照）。
- **D-011 模擬試験の配点**：学科は1問1点（公式）。実技は1問あたり配点が公表されていないため均等配点（3級5点・2級2.5点）とし画面に「独自仕様」と表示。
  複数解答欄の問題は全欄正解で正解（部分点なし）とする独自仕様。
- **D-012 模擬試験の構成**：①公表1回分をそのまま、②ランダム（公表問題の分野配分：3級=各分野 正誤5＋択一5、2級=各分野10）。不足時は制限事項を表示。
- **D-013 法令基準日の扱い**：問題ごとに出題時の法令基準日を保持し、受験予定日の基準日より古い場合は注意表示。確認済み改正と影響（正答への影響有無）を問題に紐づける。
  正答が変わる改正の対象問題は自動的に出題停止。
- **D-014 Playwright**：環境に合わせ @playwright/test を 1.56.1 に固定（プリインストール Chromium 1194 と一致）。iPhone 13 プロファイル＋デスクトップの2構成。
- **D-015 四択以外のオリジナル問題（ケース）**：`scripts/original/fporig/cases.py` に `Case`/`CaseBatch` を追加（四択の `Q`/`Batch` は不変）。
  実技形式（`j2o_<バッチ>.json`、exam=j2、設例＝materials＋3〜5小問 numeric/choice/truefalse）と、学科の四択以外（`g2n_<バッチ>.json`、exam=g2、
  ○×・語群補充・組合せ・三択、`tags` に「四択以外」）を出力。数値の正答はバッチ内のPythonで計算した値（steps を解説に出力）、法令・制度の記述は各小問に公式ページの引用を必須とし、
  数学的定義だけの計算は `math=True` で引用を省略可（ケース全体では引用1つ以上）。小問ごとの解説は `standard`（`【小問n】`）に出力。
  四択以外の問題（`tags` に「四択以外」）は2級学科のランダム模擬試験（四答択一60問構成）から除外する。
- **D-016 同じ日の再正解は復習間隔を伸ばさない**（2026-11-04、外部監査 R2-L01＝EXT-L04）：SM-2 の `review` は、同じ日に正解済み（reps>0）の問題を再び正解しても状態を変えない。
  詰め込みで次回復習が先送りされるのを防ぎ、定着は日をまたいだ想起で判断する。同じ日の不正解は従来どおり間隔を1日に戻し、不正解→正解は初回正解（2日）として扱う。
- **D-017 UIルール4点の適用方針**（2026-11-04、監査指令書の追記）：見出しの補足（`PageTitle sub`）は件数など「いま見ている内容」に限り、説明・注意書き・出典は画面下部の `PageNote` に置く。
  一覧では問題文を「…」で切らず、欠けのない識別名（出典・論点名。`questionLabel`）を表示し、問題文は検索時のみ全文表示。用語集の一覧は用語名の索引にし、検索時に定義を全文表示。
  上部バーは 48px（境界線込み49px）。演習の開始ボタンは下部ナビの上に固定。これらは `e2e/round2.spec.ts` で検査する。
