# 金融リテラシー検定モード追加：実装と多角監査の記録（2026-11-25）

ユーザー指示（2026-11-25）により、きんざい（一般社団法人金融財政事情研究会）の金融リテラシー検定を、FP3級・FP2級と並ぶ最上位レイヤーの独立ユニットとして追加した。設計判断は `docs/DECISIONS.md` の D-018。

## 公式仕様（2026-11-25 公式ページで確認）
- 級なし・IBT（申込後180日以内に受験）・40分・50問（正誤問題35問＋三答択一式15問）・100点満点・60点合格・受験料3,300円・法令基準日2026-04-01
- 出題5分野：A ライフプラン・キャリア／B 消費者トラブル・消費者信用／C 金融・経済／D 金融商品・保険／E 社会保険・税金
- 公式過去問は非公開のため、問題は全問オリジナル。分野ごとの内訳と1問あたりの配点は公式未公表のため、アプリでは5分野均等（各分野 正誤7＋三択3）・均等配点（1問2点）を独自仕様として画面に明示した。

## 成果物
- 問題250問（分野別50問＝正誤35＋三択15、本番比率を再現）。独自シラバス65細目（`scripts/original/syllabus_lit.json`）を全カバー。難易度 Lv1 100／Lv2 90／Lv3 50／Lv4 10。
- 用語165語（新規114＋FP用語の共用51、いずれもリテラシー検定の分野に割当）・数字カード24枚。
- 要点まとめPDF：全量版50ページ（Drive「会計」フォルダに保管）、凝縮版12ページ（アプリ同梱 `public/pdf64/lit-summary.b64`）。
- アプリ統合：ヘッダーのユニット切替（3級／2級／リテラシー）、模擬試験（40分・50問・分野別配分）、演習・問題一覧・用語集・単語帳・統計・学習計画の各画面がユニット対応。リテラシーでは計算トレーニング導線を出さない。

## 多角監査（全角度を1ラウンドで実施）
1. **ブラインド解き直し**：正答キーを見せずに250問全問を解き直し、キーと機械比較。一致249/250。不一致1件（住民税所得割の記述）は総務省の公式説明と照合してキーが正しいと裁定し、解説に税額控除の注記を追加した。解き直し側のフラグ3件（無期転換ルール・賃貸初期費用の目安・仲介手数料）も一次情報で裁定し、いずれもキー維持（実質的な正答キー誤り0件）。
2. **構造・バイアス**：三択の正答位置は 1:30／2:25／3:20（χ²=2.0、有意な偏りなし）。正誤の正答は ○90／×85。
3. **根拠引用の照合**：lit の全439項目（解説250・用語165・カード24）の引用833件超を、build_content と同一の取得・照合方式で公式ページと照合し、全項目 verified。照合の過程で次の出典差し替えを行った（いずれも差し替え先で逐語照合済み）。
   - 協会けんぽ（kyoukaikenpo.or.jp）が2026-11-25午後に到達不能となったため、任意継続の問題2問は藤沢市の公式ページ、出産育児一時金の問題は厚生労働省「出産育児一時金等について」、高額療養費の問題は藤沢市「国民健康保険 高額療養費」に差し替え。
   - 用語「健康保険」の療養の給付の裏づけは、協会けんぽFAQ・e-Gov法令ページに到達できなかったため、健康保険法63条・74条の条文に基づく Wikipedia「療養の給付」の条文引用に差し替え（出典名に理由を明記）。
   - 用語「公的年金制度」「厚生年金保険」は厚生労働省ページの数字の全角・半角混在に合わせて引用を修正し、再照合で一致を確認。
   - 財務省キッズページ（ふりがな混入で照合不能）・厚生労働省PDF（本文抽出不能）に依存していた用語4語は、国立国会図書館レファレンス協同データベース・国税庁 税の学習コーナー・財務省『ファイナンス』誌HTMLに差し替え。
4. **実ブラウザ操作**：Playwright でローカルプレビューをデスクトップ（1280px）と iPhone 相当（375px）の両方で操作。ユニット切替、演習（分野選択→開始→正誤問題に回答→判定・解説表示）、模擬試験画面の仕様表示、用語集（要点まとめPDFボタン・差し替え後の用語の表示）、単語帳（189枚の内訳表示）を確認。横はみ出し・文字の切れはなし（単語帳ヘッダーの6px差は実画面で全文表示を確認し問題なしと判定）。
5. **テストゲート**：tsc 合格。Vitest は全189件のアサーションが合格（うち3ファイルはこの実行環境の処理速度では既定の5秒制限を超えるため、制限を60秒に広げて全件合格を確認。アサーション自体の失敗は0件。14:22のフル実行では既定制限でも全件合格）。
