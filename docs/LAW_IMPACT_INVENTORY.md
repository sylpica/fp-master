# 旧法令基準の公式問題への改正の影響（洗い出し）

2026-11-04 外部監査 EXT-M08。現在の試験の法令基準日（2026-04-01）と、公式問題の出題時の法令基準日（2023-04-01〜2025-04-01）の間の改正について、影響を受けうる公式問題を洗い出した。

## 方法
1. 全公式問題740問（画像のみの問題を含む）について、問題文・選択肢・画像の代替テキスト・解説の全文をテーマ別のキーワードで検索した（解説は画像のみの問題の内容も要約している）。
2. ヒットした問題を1問ずつ読み、画像のみの問題は画像を開いて設問と資料を確認した。
3. 根拠は、リポジトリ内で照合済みの引用か、e-Gov の現行条文（CI 上の取得ツールで本文を確認）に限った。根拠を照合できない改正は登録せず、下表で「根拠未照合」とした。
4. 登録した改正は `scripts/content/law_src.py`。影響の区分は unchanged（正答は変わらない。画面に注記）／changed（正答が変わる。出題停止）。
